# Guía del proyecto VELATEK

## Interfaz web
Para cualquier trabajo de diseño o React/Next.js, aplica primero las skills de `.agents/skills` correspondientes:
- `frontend-design` para dirección visual intencional y composición no genérica.
- `vercel-react-best-practices` para patrones React/Next.js y rendimiento.
- `velatek-odoo-app-ui` para marca, servicios, interacción y recursos oficiales de aplicaciones Odoo.

Usa los iconos locales de `public/images/odoo/apps` al representar apps Odoo. Para componentes, reutiliza `src/components/ui` y configura shadcn en `components.json`; adapta el tema a los colores negro y verde del logo oficial de VELATEK. Mantén el wordmark VELATEK solo como texto y conserva el alcance comercial indicado por `velatek-odoo-app-ui`.
